# SmartOsint
- Outil OSINT simple pour smartphone.

### Fonctionnalités
```text
- Lookup numéro (pays, opérateur)
- Lookup email (fuites de données)
- Géolocalisation IP
- Infos modèle smartphone
```

### Utilisation
```python
python smartosint.py --number +33612345678
```  
```python
python smartosint.py --email exemple@mail.com
```
```python 
python smartosint.py --ip 91.121.77.52
```
```python 
python smartosint.py --model "iPhone 12"
```
