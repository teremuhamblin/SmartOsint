### 🧠 Fonction du projet
- SMARTOSINT permet d’obtenir des informations OSINT basiques sur un smartphone :
   - Numéro → opérateur + pays  
   - Email → fuites de données  
   - IP → géolocalisation approximative  
   - Modèle → infos du smartphone
